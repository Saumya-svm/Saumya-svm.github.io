# saumya-svm.github.io

Personal academic homepage of Saumya Mundra, built with the
[academic-homepage](https://github.com/luost26/academic-homepage) Jekyll template.

- Profile, education, experience: `_data/profile.yml`
- Publications: `_publications/<year>/*.md`
- Projects: `_showcase/*.md`
- Navbar: `_data/navigation.yml`

Preview locally with `bundle exec jekyll serve`.
